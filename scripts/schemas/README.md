# Validation schemas

These unmodified Agent Plugins 1.0.0 schemas were retrieved on 2026-10-17:

- `plugin.schema.json`: https://agent-plugins.org/schemas/1.0.0/plugin.schema.json
- `mcp.schema.json`: https://agent-plugins.org/schemas/1.0.0/mcp.schema.json

Keeping the versioned schemas here makes validation reproducible and independent
of network access. The schemas do not validate client extension semantics;
repository checks validate package paths and generated compatibility packages.
